# Phone-Number-Detail-Finder
Python Project that retrieves details about a phone number.

## Features
- Checks whether the number is valid
- Checks whether the number is possible
- Shows the country/region
- Shows the carrier (SIM provider)
- Shows the international format

## How to Run
1. Install Python
2. Install the required library:
   pip install phonenumbers
3. Run the program:
   python main.py
4. Enter a phone number with the country code (e.g. +91XXXXXXXXXX)
